### Week 11 Objectives:

* Deploy containerized applications on AWS using Docker, Docker Compose, and Amazon ECR; Manage and scale containers automatically with Amazon ECS (Service Discovery, ALB); Automate processes with CI/CD Pipelines (GitHub Actions/GitLab CI) and monitor logs/containers.

### Week 11 Achievements:

* Master building and deploying containerized applications with Docker, Docker Compose, and managing them on Amazon ECR.
* Understand the roles of ECS Clusters, Task Definitions, ECS Services, ALBs, and Service Discovery.
* Successfully set up CI/CD pipelines to automate container development and deployment.
* Know how to use Container Insights and FireLens to manage and monitor container logs and performance on AWS.
