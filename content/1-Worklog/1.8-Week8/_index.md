### Week 8 Achievements:

* Understand the role of Route 53, Inbound/Outbound Resolvers, and Rules in a Hybrid Cloud environment.
* Master installing, configuring AWS CLI Profiles, and basic CLI commands to manage AWS resources.
* Understand the VM Import/Export mechanism for migrating virtual machines from on-premises to EC2.
* Understand the difference between Schema Conversion (SCT) and Data Migration (DMS).
* Know how to use Lambda to automate administrative tasks and optimize EC2 operating costs.
