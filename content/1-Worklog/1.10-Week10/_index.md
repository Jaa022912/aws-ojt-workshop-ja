### Week 10 Objectives:

* Manage centralized access with IAM Identity Center, limit advanced permissions using Permission Boundaries and IAM Role Conditions; Monitor system security with AWS Security Hub and AWS WAF.

### Week 10 Achievements:

* Understand how to manage users and Permission Sets centrally through IAM Identity Center.
* Master the operation of Permission Boundaries and their role in preventing privilege escalation.
* Successfully configure IAM Role Conditions to tighten access security based on IP and time.
* Know how to use Security Hub to track Compliance Scores and detect security risks.
* Master configuring Web ACLs on AWS WAF to protect web applications at the application layer (Layer 7).
