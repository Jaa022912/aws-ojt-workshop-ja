# Event Report: AWS First Cloud AI Journey Community Day – June 2026

## Event Objective

The **AWS First Cloud AI Journey Community Day – June 2026** was organized to introduce the latest trends in Artificial Intelligence (AI) and Cloud Computing. Through technical presentations and live demonstrations, the event provided participants with practical insights into how modern AI technologies are being applied in enterprise environments.

The objectives of the event were:

- Introduce the latest trends in AI and Cloud Computing.
- Showcase practical AI applications built on AWS.
- Share real-world experiences in adopting AI for businesses.
- Provide learning opportunities through knowledge sharing by industry experts.

## Event Highlights

The event covered a variety of emerging topics in Artificial Intelligence and Cloud Computing, including:

- AI Agents
- Voice AI
- DevOps Automation
- MCP Security
- Practical AI applications on AWS

Throughout the event, the speakers shared real-world use cases demonstrating how organizations leverage AI to improve productivity, automate workflows, and develop modern cloud-native solutions on AWS.

The live demonstrations provided practical examples that helped participants better understand how these technologies are implemented in enterprise environments.
