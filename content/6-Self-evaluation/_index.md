During my internship at **Amazon Web Services (AWS) Vietnam - First Cloud AI Journey (FCAJ) Workforce Bootcamp** from **June 2, 2026** to **July 29, 2026**, I had the opportunity to apply the knowledge gained at university while developing practical skills in a professional working environment.

During the internship, I participated in the development of the **AI AWS Advisor** project, an intelligent platform designed to monitor AWS resources, analyze security, evaluate system performance, and optimize cloud costs using AI. The project was built on a **serverless architecture** using AWS services such as **AWS Lambda, Amazon API Gateway, Amazon DynamoDB, Amazon CloudWatch, Amazon EventBridge, Amazon SNS, and Amazon Bedrock**. To improve system performance and security, the architecture also incorporated **Amazon CloudFront**, **AWS WAF**, **Amazon Cognito**, and **JWT-based authentication**. In addition, a **Rule Engine** was implemented to classify findings into **Critical**, **High**, **Medium**, and **Low** severity levels before AI generated explanations and recommendations, ensuring more accurate and consistent analysis.

Through this project, I strengthened my knowledge of **Cloud Computing**, **Serverless Architecture**, **RESTful API development**, user authentication with **JWT**, and various AWS services. I also gained experience in building technical documentation with **Hugo** and **Markdown**, while improving my teamwork, communication, technical writing, and problem-solving skills.

Throughout the internship, I maintained a proactive attitude, completed assigned tasks on time, followed the team's workflow, and actively collaborated with mentors and teammates to improve the quality of my work.
